# GrowMeal visual and instructional content quality standard

**Scope:** Every class, garden, lesson, activity, question, flashcard and future garden sequence.

## Non-negotiable rules
1. Each instructional image or diagram has a unique asset ID and is used for exactly one instructional activity. Never reuse an instructional image in another question or garden.
2. The image must directly depict the objects, quantities, colours, labels, spatial relationships or process asked about. A shared decorative scene is not an acceptable substitute.
3. Counting tasks must show the exact count; identification tasks must depict the target; sequencing tasks must depict the stated sequence. All options and answer keys must agree with the displayed visual.
4. Age-appropriate scientific accuracy, accessibility (descriptive alt text), contrast, mobile layout and child safety are required.
5. All teacher guides must include complete answers and explain any diagram simplifications. Illustrative diagrams must not be presented as real field observations.
6. Do not declare a garden complete solely because its component is committed. Verify visual uniqueness, visual-question correspondence, interaction correctness, responsive layout, build and browser acceptance.
7. Where a question does not require an image, use a deliberately text-only layout rather than unrelated filler imagery.

## Required content schema for new packs
Each question should have a unique question ID, a unique visual asset ID (or explicit no-image value), visual description/alt text, prompt, choices, correct answer, explanation and curriculum objective.

## Acceptance checklist
- [ ] All visual asset IDs are unique within the pack and across the garden asset registry.
- [ ] No image file or visual composition is reused in another activity.
- [ ] Reviewer verifies each question against its own rendered visual.
- [ ] Counts, colours, labels, patterns and answer keys are consistent.
- [ ] Visuals remain readable on mobile and for assistive technology.
- [ ] Functional interaction tests pass.
- [ ] Build and browser tests pass before marking the pack accepted.

**Rollout:** Existing first-garden packs and the Nursery 1 second-garden pack require retrospective visual audit. The Nursery 2 second-garden pack was corrected to use eight unique question-specific inline SVG scenes; full browser acceptance remains pending.
