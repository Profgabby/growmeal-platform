# Location-aware planting calendars

Do not assign a universal Nigerian planting date. Collect country, state/region, growing season, rainfall/irrigation access, sunlight, temperature where available, and container/field context. Resolve agroecological zone and use reviewed crop-specific guidance. Display uncertainty and seasonal alternatives. Do not promise harvest dates; compute indicative windows from sowing/transplanting dates only when verified crop data is available.

Calendar stages: prepare → sow/transplant → germination → establish → maintain → first edible harvest → mature harvest → repeat/retire.
