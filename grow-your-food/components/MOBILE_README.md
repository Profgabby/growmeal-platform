# Mobile-first preview

Serve the repository over HTTP and open `/grow-your-food/components/mobile.html`.

This mobile-first, keyboard-accessible navigation preview uses LIFEWS forest green `#006B3C` and gold `#FDB515`. It links to the existing standalone Growing Journey interface and the 30-crop catalog. It is not integrated into Next.js, Supabase or the production homepage.

**Acceptance still required:** device/browser tests at 320/375/390/768/1024px; screen-reader navigation; Android Chrome; offline behavior; safe-area insets; keyboard form usability; persistence; end-to-end growing workflow.

**Safety:** no real-time seasonal planting recommendations, no crop disease diagnosis, no child profile collection.
